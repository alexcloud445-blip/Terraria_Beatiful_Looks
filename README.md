# Beautiful Looks (Terraria / tModLoader)

Косметический мод: крылья, ауры, костюмы. Никакого влияния на баланс, только красота.

## Что уже есть (v0.5)
- **Меню Beautiful Looks** (клавиша **K**): широкое окно справа от персонажа, живое превью, общий выключатель эффектов, вкладки:
  - **Аура**: 17 стилей (сияние, искры, кометы с хвостами, пламя, звездопад, мороз, сакура, сердечки, вихрь, кольцо рун, гроза с молниями, пустота, божественный свет, призма, бабочки, руны, светлячки) + ползунки плотности, размера и скорости
  - **След**: светящаяся лента на шейдерах Terraria (мягкая, радужная, пламенная, Императрица, двойная спираль), 11 видов частиц, призрачные копии персонажа (призрак, шлейф, фантом)
  - **Эффекты**: 5 стилей нимба, сияние, тонкие вращающиеся лучи, круг, магический сигил, пульсирующие кольца, **светящийся контур** персонажа, перекраска ванильными красками
  - **Рывок**: 7 стилей (вспышка, тень, пламя, гроза, призма, сакура, пустота) — звуковая волна, линии скорости, росчерк и цветные послеобразы; работает с любым рывком, в том числе из Calamity
  - **Крылья**: 8 видов крыльев из эффектов с анимацией взмахов (серафим, свет, бабочка, демон, пламя, кристалл, созвездие, дух), поверх любых крыльев или без них
  - **Цвета**: у ауры, следа, эффектов и крыльев по два цвета (+ радуга), 12 тем
  - **Образы**: 10 готовых образов (Серафим, Инферно, Мороз, Сакура, Пустота, Императрица, Гроза, Небесный, Фея, Комета)
  - **Гардероб**: все предметы мода с подсказками
  - 5 слотов пресетов, «Случайно», «Сброс»
- **Своя система частиц**: каждая частица переливается градиентом (белое ядро → основной цвет → второй → угасание), цвета смешиваются по цветовому кругу; 24 формы (сердце, лепестки, лист, снежинки, звёзды, ромб, осколки, полумесяц, перо, капля огня, пузырь, бабочка, спираль, планета, лотос, огонёк-комета) с мягким свечением
- **Крылья** (6 предметов) теперь сами рисуются эффектами, **головные уборы** (5), **плащи** (3)
- Образ сохраняется вместе с персонажем и синхронизируется в мультиплеере
- Настройки мода: сила эффектов, лимит частиц, шейдерные ленты вкл/выкл, показывать образы других игроков
- Перевод: английский и русский

## Установка для разработки
1. Установить **tModLoader** (Steam, бесплатно) и запустить его хотя бы раз.
2. Склонировать репозиторий в папку
   `Документы\My Games\Terraria\tModLoader\ModSources\`
   (папка мода должна называться `Terraria_Beatiful_Looks`).
3. В игре: **Workshop → Develop Mods → Build + Reload**.

## Структура
```
BeautifulLooksMod.cs             главный класс, сетевые пакеты
Common/Looks/                    данные образа (LookSettings, ColorSetting)
Common/Players/LooksPlayer.cs    сохранение, пресеты, синхронизация, запуск эффектов
Common/VFX/                      своя система частиц, шейдерные ленты, встраивание в отрисовку кадра
Common/Effects/                  ауры, следы, призрачные копии, нимбы и круги (PlayerDrawLayer)
Common/UI/                       окно меню и элементы (кнопки, ползунки, палитра)
Common/Systems/                  горячие клавиши, подключение меню
Common/Configs/                  настройки мода
Content/Dusts/                   свои частицы
Content/Items/Wings/             крылья (CosmeticWings + наследники)
Content/Items/Vanity/            уборы (CosmeticHat) и плащи (CosmeticCape)
Assets/VFX/                      текстуры эффектов (генерирует tools/make_vfx.py)
Localization/                    тексты (en-US, ru-RU)
tools/make_sprites.py            генератор спрайтов предметов
tools/make_vfx.py                генератор текстур эффектов (+ make_vfx_shapes.py: формы, крылья, блики)
tools/stubcheck/                 проверка компиляции без игры (для разработки)
```

## Как добавить своё
- **Крылья**: новый класс-наследник `CosmeticWings` с `[AutoloadEquip(EquipType.Wings)]` и два PNG: иконка и `Имя_Wings.png` (4 кадра 86x56 сверху вниз)
- **Убор**: наследник `CosmeticHat` с `[AutoloadEquip(EquipType.Head)]`, PNG иконки и `Имя_Head.png` (20 кадров 40x56)
- **Плащ**: наследник `CosmeticCape` с `[AutoloadEquip(EquipType.Back)]`, PNG иконки и `Имя_Back.png` (20 кадров 40x56)
- **Стиль ауры**: значение В КОНЕЦ `AuraStyle`, метод в `AuraEffects`, строка `UI.Aura.Имя` в локализации
- **Своя частица**: наследник `Particle` (Common/VFX), создаётся через `ParticleSystem.Spawn(...)`
