# Beautiful Looks (Terraria / tModLoader)

Косметический мод: крылья, ауры, костюмы. Никакого влияния на баланс, только красота.

## Что уже есть (v0.1)
- **Меню Beautiful Looks** открывается клавишей **K** (переназначается в Настройки → Управление). В нём выбор стиля ауры (Выкл / Свечение / Искры / Орбита) и её цвета. Выбор сохраняется вместе с персонажем.
- **Звёздные крылья**: 10 перьев + 5 упавших звёзд, крафт у наковальни. Светятся и сыплют звёздной пылью.
- **Звёздная корона**: украшение на голову, 4 золотых или платиновых слитка + 2 звезды, крафт у наковальни.
- **Настройка яркости ауры**: Настройки → Конфигурация модов → Beautiful Looks.
- Перевод: английский и русский.

## Установка для разработки
1. Установить **tModLoader** (Steam, бесплатно) и запустить его хотя бы раз.
2. Склонировать репозиторий в папку
   `Документы\My Games\Terraria\tModLoader\ModSources\`
   (папка мода должна называться `Terraria_Beatiful_Looks`).
3. В игре: **Workshop → Develop Mods → Build + Reload**.

## Структура
```
BeautifulLooksMod.cs          главный класс мода
Common/Players/LooksPlayer.cs аура, сохранение настроек персонажа, горячая клавиша
Common/Systems/               горячие клавиши, подключение меню
Common/UI/LooksPanel.cs       окно меню
Common/Configs/               настройки мода
Content/Items/Wings/          крылья (код + иконка + _Wings.png из 4 кадров 86x56)
Content/Items/Vanity/         костюмы (код + иконка + _Head.png из 20 кадров 40x56)
Localization/                 тексты (en-US, ru-RU)
tools/make_sprites.py         генератор спрайтов-заглушек
```
